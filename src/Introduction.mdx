# FABi CMS Design System

Component library and documentation of FABi CMS.

- **Getting Started**: install the `@fabi/ui` package, wrap the app in `FabiProvider`, the import and class prefix maps.
- **Design Tokens**: changing the theme, the Seed / Map / Alias token tables, colors, dark mode, font, layout,
  shadow, motion.
- **Components**: each page has an introduction, examples, API, Semantic DOM, Design Token and FAQ.
- Every example is a story; click **Show code** under an example to see its code (it imports from `@fabi/ui` and runs
  as is in an app).
- Brand: primary color **Geek Blue** (`#1d39c4`), font **Be Vietnam Pro**, cards with an **8px** radius and
  **Medium 500** titles. Every table uses the bordered style (`bordered`).
- The **Language** toolbar (VN / EN) switches the docs language: titles and descriptions. Code, component names, story
  names and the text the components draw themselves stay as they are.

Generated with `npm run convert` and `npm run convert:pages`; do not edit the generated files by hand.

</En>
