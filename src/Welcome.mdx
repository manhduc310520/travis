# Welcome to FABi Design System

FABi's own component library, tuned to the FABi Figma file. Every screen in
FABi CMS is composed from the same components documented here, themed
through one shared theme provider.

**Figma source:** `hneVCBNUiPizVorg7Jp18G` — *Design Component Desktop*

## How theming works

5 brands × 2 modes × 2 densities = 20 live theme combinations, all switchable
from the toolbar above:

Every story reacts to all three — pick a brand and mode, then browse
Components below to see it applied consistently everywhere.

## Where to go from here

- **Design Tokens** — color, border, font and spacing values, each shown as
  a real `var(--...)` alongside its resolved value, plus the full
  `@untitledui-pro/icons` catalog (searchable — matches the Figma file's icon
  page).
- **Components** — every component in the FABi library, organized
  alphabetically.
- **Templates** — `AppShell`, `AppHeader`, `RestaurantListPage`: the layout
  layer built specifically for FABi CMS, rebuilt from Figma's own frames.
