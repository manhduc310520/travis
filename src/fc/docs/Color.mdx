# Color

Each row is one Figma variable (collections `0. Global`, `1. Brand`, `2. Colors`). The **CSS** column
matches the Code syntax in Dev Mode; the **Value** column is the value the browser currently
resolves — switch **Brand** or **Mode** in the toolbar to watch it change.
Variable names never change with the theme. In Figma, names are Title Case
(`Color/Content/Neutral-Strong`); the CSS variable is the same path in lowercase
(`--fc-color-content-neutral-strong`). Naming rules: `docs/token-naming-spec.md`.

## Palette — `Color/Palette`

12 ramps × 10 steps, plus `accent` (the ramp of the selected brand). Follows **Mode**:
the same name is a light color in Light and a dark color in Dark. Use directly only for tags,
charts and categorization — never for buttons or primary UI.

<Canvas of={ColorStories.Palette} />

## Brand — `Brand/Light`, `Brand/Dark`

The layer that follows **Brand**, already split into Light and Dark sides. Do not use it directly in
components — go through `Color/*`.

<Canvas of={ColorStories.Brand} />

## Base values — `Global/Light`, `Global/Dark`

Collection `0. Global`: a single mode, does not change with the theme, hidden from the Figma library.
It is only the source for the layers above — **never** use it directly.
