# Màu

Mỗi dòng là một biến trong Figma (collection `0. Global`, `1. Brand`, `2. Colors`). Cột **CSS**
trùng với Code syntax trong Dev Mode; cột **Giá trị** là giá trị trình duyệt đang
tính ra — đổi **Brand** hoặc **Mode** trên thanh công cụ để xem nó đổi theo.
Tên biến không bao giờ đổi theo theme. Trong Figma tên viết hoa chữ đầu
(`Color/Content/Neutral-Strong`); biến CSS là cùng đường dẫn viết thường
(`--fc-color-content-neutral-strong`). Quy tắc đặt tên: `docs/token-naming-spec.md`.

## Bảng màu — `Color/Palette`

12 dải × 10 bậc, cộng `accent` (dải của brand đang chọn). Đổi theo **Mode**:
cùng một tên cho màu sáng ở Light và màu tối ở Dark. Chỉ dùng trực tiếp cho tag,
chart, phân loại — không dùng cho nút hay UI chính.

<Canvas of={ColorStories.Palette} />
