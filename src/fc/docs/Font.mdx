# Chữ

Biến trong Figma collection `4. Typography`. Cỡ chữ gốc 14px; đổi **Density** sang
Compact để xem cỡ chữ và line-height thu lại. Màu chữ nằm ở trang **Màu**
(`Color/Content`).
