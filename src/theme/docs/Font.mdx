# Font Tokens

Sourced from the Figma collection `4. Typography` (`src/theme/typographyTokens.ts`,
`src/theme/index.ts`). The tables below are pinned to the Default density
value for a stable reference, the same way every other Design Tokens page
here works — switch the **Density** toolbar on any *component* story (not
this one) to see `fontSize`/heading sizes and line-heights actually shrink to
Figma's Compact numbers live.

## Font Family

Only two family tokens: `fontFamily` for everything, `fontFamilyCode` for
`<Typography.Text code>` and antd's own `<code>` elements.

<Canvas of={FontStories.Family} />

## Font Weight

Per the design system's own rule (see the project's `CLAUDE.md`): **only two
weights** anywhere in the UI — Regular 400 for body/control/menu/tab, Semibold
600 for heading/table-header/title. No thin, no 700+, no italic.
Active/selected state is shown with color and an underline or border, never
with extra weight. Figma's own `4. Typography` collection also defines a
Medium 500 — kept here for reference since it is a real token there, though
nothing in this library currently uses it.

<Canvas of={FontStories.Weight} />

## Font Line Height

Ant Design's line-height tokens are unitless ratios, not px — e.g.
`lineHeightHeading1: 1.21` means 1.21× whatever `fontSizeHeading1` resolves
to at the current density, not a fixed 46px.
