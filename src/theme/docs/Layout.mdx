# Layout Tokens

## Spacing

Every gap and padding in the system snaps to this scale — all multiples of
4, per the project's own grid rule. Base `padding` is 16px, moved down from
the library default of 24. Switch **Density** to Compact in the
toolbar to see the whole scale shift at once (`src/theme/dimensionTokens.ts`).
