# Font Tokens

## Sizes

`fontSize: 14` and `fontFamily` are the only two type tokens FABi's Figma
export actually overrides (`src/theme/index.ts`, `globalTokens`). Heading
sizes below come from the library's own default scale — FABi has not
replaced them with Figma-specific values yet.

<Canvas of={TypographyStories.Sizes} />

## Weight

Per the design system's own rule (see the project's `CLAUDE.md`): **only
two weights** anywhere in the UI — Regular 400 for body/control/menu/tab,
Semibold 600 for heading/table-header/title. No thin, no 700+, no italic.
Active/selected state is shown with color and an underline or border, never
with extra weight.

## Headings

`Typography.Title` at each level, rendered with the live theme so this
matches what `fontSizeHeading1`–`fontSizeHeading3` above actually produce.

<Canvas of={TypographyStories.HeadingsStory} />

## Text variants

`Typography.Text` semantic types plus `Link` — color and weight carry the
meaning, never a third font weight.

<Canvas of={TypographyStories.TextVariantsStory} />

## Body copy

`Typography.Paragraph` at body size, capped to a comfortable reading width.
